# Интеллектуальная система маршрутизации воздушных судов

> Прототип системы динамической оптимизации траектории полёта с учётом погодных, навигационных и эксплуатационных факторов на основе мультиагентного обучения с подкреплением.

## О проекте

Система решает задачу совместной маршрутизации нескольких воздушных судов в динамической воздушной среде. В отличие от классических алгоритмов поиска на графе (Дейкстра, A\*), которые работают в статичных условиях и требуют полного перепланирования при любом изменении обстановки, данный прототип использует **табличный Q-learning** — метод обучения с подкреплением без модели среды. После обучения система принимает решение о следующем манёвре за **O(1)** независимо от числа агентов и протяжённости маршрута.

Задача формализована как **марковский процесс принятия решений (MDP)**:
- пространство состояний: **|S| = 1 470** (прогресс, эшелон, отклонение курса, конфликт, стагнация, прогноз погоды)
- пространство действий: **|A| = 40** (5 эшелонов × 8 кандидатных навигационных точек)
- горизонт эпизода: **T = 150** шагов
- число эпизодов обучения: **N = 1 660**

Прototip разработан в интересах **ПАО «Аэрофлот»**.

## Демонстрация

На скриншоте выше — веб-интерфейс системы при расчёте двух одновременных рейсов:

- **Рейс №1**: Красноярск (KJA) → Магадан (GDX), Boeing 737-800
- **Рейс №2**: отображён на отдельной вкладке

На карте показаны: цветовая метеообстановка по скорости ветра, грозовые фронты, запретные зоны (штриховка), встречные самолёты, навигационные точки и рассчитанный маршрут. Ползунок времени `T = 16` позволяет просматривать динамику погоды и трафика на каждом шаге симуляции.

## Возможности

- Одновременная маршрутизация нескольких воздушных судов без централизованного координатора
- Учёт динамической метеообстановки: скорость и направление ветра, грозы, турбулентность, обледенение
- Обход запретных зон и навигационных ограничений
- Физически корректная модель топлива с учётом убывающей массы воздушного судна
- Учёт встречных бортов и норм безопасного эшелонирования
- Выбор запасного аэродрома по длине ВПП и топливным ограничениям
- Интерактивная карта на Leaflet.js с визуализацией маршрута, погоды и трафика в реальном времени
- Три режима запуска: `train`, `resume`, `inference`

## Архитектура

```
flightplanner/
├── flight_env.py          # Агентная среда (MDP, Q-learning, модель ВС)
├── weather_gen.py         # Генерация погодных данных (шум Перлина, 932 500 записей)
├── simulator.py           # Симуляция встречных ВС (A*, 50 позиций)
├── agent/                 # Q-таблицы агентов (q_table_agent1.pkl, q_table_agent2.pkl)
├── airports/              # russian_civil_airports.json
├── data/
│   ├── weather_data.json          # Погода: 1865 waypoints × 5 эшелонов × 100 шагов
│   ├── allowed_to_use_waypoints.json
│   ├── prohibited_zones.json
│   └── simulation_result.json
├── templates/
│   └── index.html         # Веб-интерфейс (Leaflet.js)
└── app.py / server.py     # Flask API
```

### Ключевые классы (`flight_env.py`)

| Класс | Назначение |
|---|---|
| `WeatherDB` | Индексирует погоду по `(z, t)`, O(1) lookup |
| `Aircraft` | Параметры ВС: масса, топливо, ЛТХ, расход |
| `FlightState` | Вектор состояния агента, счётчик стагнации |
| `FlightEnvironment` | MDP-среда: `step()`, `reset()`, формирование наблюдений и наград |
| `QLearningAgent` | Q-таблица (dict), ε-greedy стратегия, сохранение/загрузка pkl |

## Параметры обучения

| Параметр | Значение |
|---|---|
| Скорость обучения α | 0,2 |
| Коэффициент дисконтирования γ | 0,99 |
| Начальное ε | 1,0 |
| Минимальное ε | 0,05 |
| Коэффициент затухания λ | 0,998 |
| Число эпизодов N | 1 660 |
| Максимум шагов T | 150 |

## Тестовые маршруты

| Агент | ВС | Маршрут | Расстояние |
|---|---|---|---|
| Агент 1 | Boeing 777-300ER | SVO (Москва) → VVO (Владивосток) | 6 430 км |
| Агент 2 | Airbus A350-900 | LED (Санкт-Петербург) → PKC (Петропавловск-Камчатский) | 7 720 км |

**Результаты обучения (1 660 эпизодов):**
- Агент 1: средняя награда 16 000 → 53 000; доля успешных прилётов 28% → 58%
- Агент 2: маршрут 7 720 км при лимите 150 шагов; средняя награда ~16 000; доля прилётов ~4–5%

## Данные среды

- **Навигационные точки**: 1 865 точек, спарсенных с [opennav.com](https://opennav.com/waypoint/RU)
- **Погода**: 932 500 записей (1 865 точек × 5 эшелонов × 100 временных шагов), сгенерированы с использованием шума Перлина, 12 центров давления, 4 грозовых фронта
- **Аэропорты**: гражданские аэропорты России, классифицированные по длине ВПП (порог 3 000 м для тяжёлых ВС)
- **Запретные зоны**: полигоны с проверкой пересечения методом ray-casting

## Входные данные

При запуске системе передаются:

- **Аэропорты** вылета и назначения (координаты, код ИКАО)
- **Тип воздушного судна** (B737-800, B773ER, A350 и др.) — ЛТХ загружаются из пресетов
- **Загрузка борта**: количество пассажиров (средняя масса 80 кг/чел.), масса багажа
- **Минимальный резерв топлива** для ухода на запасной аэродром (по умолчанию 5 000 кг)

## Выходные данные

- `two_planes.json` — детализированные маршруты обоих агентов: координаты каждой навигационной точки, эшелон, расход топлива, остаток, погода, штрафы, дистанции до других бортов
- `q_table_agent1.pkl`, `q_table_agent2.pkl` — обученные Q-таблицы для повторного использования
- `route_map.html` — интерактивная карта маршрутов
